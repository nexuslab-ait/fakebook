# Futures Fakebook

A shared class feed for **FUTURES · Module 2 · Activity 2.3** (ED82.13, Asian Institute of Technology).

Students imagine a future where their adaptation challenge has been successfully addressed, then post it from that year: a headline, an image, what changed, a voice from the future and a short story. Everyone scrolls one feed together.

- Website: GitHub Pages (`index.html`, `app.js`, `style.css`, `config.js`)
- Storage: a Google Sheet for posts and a Google Drive folder for uploaded images, through the Apps Script in `apps-script/Code.gs`
- Settings: `config.js`

Without a `scriptUrl` in `config.js`, the site runs in demo mode and saves posts only in the visitor's own browser.

See `SETUP.md` for step-by-step setup.
